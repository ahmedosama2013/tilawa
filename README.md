# 🌙 Tilawa

**Tilawa** is a clean, dark-mode Quran reader and audio player built with plain HTML, CSS, and JavaScript to make reading the Holy Quran with translations and listening ayah by ayah accessible, structured, and distraction-free.

## ✨ Features
- **The Holy Quran:** Read all 114 surahs in Uthmani Arabic script (Amiri Quran) with adjustable text sizes, quick search by name or number, and shareable deep links to any surah or ayah.
- **Translations & Transliteration:** Switch seamlessly between English (Sahih International), Urdu (Jalandhry), full transliteration, or Arabic-only mode.
- **Five Renowned Reciters:** Listen to verse-by-verse audio recitations by Mishary Rashid Alafasy, Mahmoud Khalil Al-Husary, Abdul Basit Abdus-Samad, Yasser Al-Dosari, and Abdul Rahman Al-Sudais with automatic continuous playback across surahs.
- **Customizable Audio Player:** Full playback controls featuring seek bar, single-ayah repeat, and adjustable playback speeds from 0.75x to 1.5x.
- **Bookmarks & Offline Support:** Save favorite ayahs in the Saved tab, retain reading preferences automatically in the browser, and install Tilawa as a Progressive Web App (PWA) for offline text access.

## 📱 Install as an App (PWA)
You can install Tilawa directly to your home screen or desktop from any supporting browser for an app-like reading experience and offline access to previously opened surahs.

---

To provide certain features, the app connects to third-party services.

Al-Quran Cloud (api.alquran.cloud): supplies the Uthmani Quran text, translations, transliteration, and audio listings.

Quran audio hosting: the recitation audio files are streamed from `cdn.islamic.network` (Alafasy, Al-Husary, Abdul Basit) and `everyayah.com` (Yasser Al-Dosari, Abdul Rahman Al-Sudais).
